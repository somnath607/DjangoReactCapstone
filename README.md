# Car Dealership Review Application

## Project Overview
This project is a full-stack web application developed using Django and React.

The application allows users to:
- Register and log in.
- View available car dealerships.
- View dealership details.
- Read customer reviews.
- Add reviews for dealerships.
- Manage user authentication.

## Technologies Used
- Python
- Django
- Django REST Framework
- React.js
- HTML
- CSS
- JavaScript
